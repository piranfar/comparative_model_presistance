Dataset variables

Group     = Numeric variable for treatment [0: untreated , 1: 1x MIC moxifloxacin, 2: 10x MIC moxifloxacin, 3: 1x MIC isoniazid, 4: 10x MIC isoniazid] (for details see 'Sample')
Replicate = Replicate number
Time      = Timepoints in days
CFU       = Colony forming units in CFU/mL
CFUlog10  = Log10 transformed CFU
Condition = Numeric variable for plating condition [0: 100uL quad, 1: 10uL 4 drops 2: 10uL single drop 3: 2.5uL single drop] (for details see 'Comments')
Volume    = Volume plated for colony counting (see also 'Condition' and 'Comments')
AQL       = Above quantification limit [0: countable culture, 1: uncountable culture/full plate]
BQL       = Below quantification limit [0: countable culture, 1: uncountable culture/too few or no colonies]
Institute = Alphabetical blinded institute code
Sample    = Detailed description of the sample
Comments  = Detailed description of the plating method /other comments
